# 倉庫番（SOKOBAN）改良版

## 概要
配布された倉庫番のベースプログラムをもとに、オリジナルステージの追加およびクリア時のランク評価機能を実装したパズルゲームです。

## 実行方法
ターミナルで以下のコマンドを実行して起動します。

```bash
python sokoban.py
```

## 操作方法
- **W / A / S / D**: プレイヤーの上下左右移動
- **U**: 1手戻す（Undo）
- **R**: 現在のステージを最初からやり直す（Restart）
- **Q**: ゲームを終了する（Quit）

## 工夫・改良した点
1. **ステージ4（オリジナルマップ）の追加**: 全4ステージ構成にし、後半のやりごたえを増やしました。
2. **クリア時のランク評価機能**: 移動回数（手数）に応じて S / A / B のランク評価と、現在のステージ番号が表示されるように改良しました。
